# 商策｜经营诊断与每日巡检

面向中小商家店长，围绕 11.11 后第 3 天的经营问题「大促后流量掉了，是正常回落还是有问题？」提供完整诊断体验。手机为主，桌面辅助查看。

## 体验

打开 [商策经营诊断](https://aurorasundev.github.io/fitness-audience-agent/)，选择问法 → 确认或修改查询计划 → 查看分步进展 → 获取结论与处理建议。可中断后继续，展开证据比较两种口径，进入预算申请与二次确认，或保存本次诊断并订阅流量巡检。

证据不足路径：在证据页点击「改用此口径重新分析」，选择商品详情页 UV 并确认，即可看到具体缺失部分，选择调整口径或转人工复核。人工复核保留单号与待处理状态。保存的分析可在入口重新打开。

main 只包含经营诊断及其保存/订阅卡；每日巡检平台仍单独保留在 `feat/daily-business-pulse`，没有合入 main。

## 每日巡检（功能分支）

打开 `?view=daily` 直接查看动燃健身旗舰店的经营日报。商家路径为：开启每日巡检 → 四维日报 → 异常证据 → 记录处理或继续经营诊断 → 返回原日报 → 次日跟进。日报可下载为独立、可交互的 HTML 文件。设置页支持暂停、恢复和提醒方式调整。

全店四维巡检与 S8 保存的诊断专项关注分别管理。专项关注仅跟进原诊断的流量范围，不自动开启全店订阅。

## 本地预览与检查

无需安装依赖。在仓库目录运行 `python3 -m http.server 4173`，然后打开 `http://127.0.0.1:4173/`。纯数据和状态机测试：`node --test tests/*.test.mjs`。

固定数据：峰值 UV 10,000、11.14 实际 6,000、相似活动参考预期 7,000；下降 4,000 中，预期回落 3,000（75%）、额外缺口 1,000（25%）。渠道贡献不等于因果，详情页无日值时不沿用店铺数据。当前数据、审批与订阅由浏览器状态驱动，生产数据、审批、消息和后台定时接口尚未接入；这些实现说明不进入商家页面。

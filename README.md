# 大促后流量诊断｜商智 App 可点击原型

作业二的教学原型：中小商家店长在 11.11 后第 3 天问「大促后流量掉了，是正常回落还是有问题？」。主端按 390px 手机宽度设计，桌面浏览器也可查看。所有数据、任务、审批和订阅均为本地模拟；不会连接真实店铺、调整预算或发送通知。

## 体验

打开 [GitHub Pages 原型](https://aurorasundev.github.io/fitness-audience-agent/)，依次点击 S1 建议问法 → S2 确认计划 → S3 执行 → S4 结论。再从结论进入 S5 证据、S7 受控操作和 S8 Skill；页面顶部的「场景」选择器可切换缺数、口径冲突、超时以查看 S6。按钮可点击，但外部操作均是演示状态。

## 本地预览与检查

无需安装依赖。在仓库目录运行 `python3 -m http.server 4173`，然后打开 `http://127.0.0.1:4173/`。纯数据和状态机测试：`node --test tests/*.test.mjs`。

演示数值：峰值 UV 10,000、11.14 实际 6,000、相似活动参考预期 7,000；下降 4,000 中，预期回落 3,000（75%）、额外缺口 1,000（25%）。渠道缺口只代表结构贡献，不证明广告或其他渠道是原因。产品详情页 UV 没有可用日值，不会继承店铺 UV。截图与数据均为课程演示内容。

参考预期是历史相似活动的**示例基线**，非真实预测。11-14 店铺 UV 相对峰值跌 4,000，其中预期回落 3,000、额外缺口 1,000；付费渠道缺口 500 属于总缺口的一部分。`500/1300=38.46%` 是付费自身下降比例；`500/1000=50%` 是付费对总缺口的结构贡献。两者分母不同，均不证明原因。

## 事件与失败脚本

- 11-11 大促峰值；11-12/13 正常回落背景，11-13“可能预算受限”仅为待验证线索。
- 11-14 命中店铺 UV 与付费渠道阈值，排名同条件下降 6 位待核验。
- 11-15/16 与预期的差距收窄；反馈“检查广告计划状态”只是本机演示记录，改善不作因果归因。
- `missing-data`：用户维度缺失，部分报告；`metric-conflict`：另来源 v0.9 的 UV 为 6,180，暂停流量结论；`rank-incomparable`：当前快照改为桌面端上海，不计算排名下降；`timeout`：查询中断只留 Trace；`unauthorized`：拒绝并记模拟审计。

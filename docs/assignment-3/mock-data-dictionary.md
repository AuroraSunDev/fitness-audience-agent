失败用例：`missing-traffic` 保留其余三域并暂停转化率；`missing-data` 仅用户维度待更新；`metric-conflict` 暂停流量及依赖分母的转化率；`rank-incomparable` 不判断排名变化；`timeout` 不输出完整日报；`unauthorized` 拒绝读取。11 月 15–16 日缺口收窄仅是后续观测，不归因为商家动作。

# 经营诊断：三条走查发现与修正

2026-10-26。核查 main 公开版本、源码与修订后的 390×844 可点击链路；同时复核 375px 和 1280px。以下是实际发现的问题，不是编造的商家反馈。

1. **人工复核内容与所选口径不一致。** 从证据页切到商品详情页 UV，数据不足后转人工，原来的通用待办仍要求补广告渠道数据。修正为随缺失原因生成待核事项；详情页分支要求补日值和对应明细。转交后显示复核单号、待处理状态、原问题和分析范围；同一诊断重复请求不会重复计入人工介入。

2. **保存入口没有真正保留本次分析。** 原先保存的是一份巡检配置，无法在刷新后重新打开这次结论、查询计划和证据。修正为保存原问题、指标版本、时间、基线、维度、结果和证据，巡检规则关联来源诊断；入口增加最近保存诊断。浏览器实测保存、暂停、恢复、刷新和重新打开，原结果没有重新取数或换口径。

3. **诊断标识不能区分同日重复分析。** 原标识由场景和数据日固定生成，同一天重复执行会复用标识，不适合追踪每次分析或计算人工介入率。改为每次诊断独立 ID；失败本身不计人工介入，主动转交时按诊断 ID 去重。自动测试验证两次诊断、一次人工转交、重复点击不加计；这只是计数逻辑验证，不是线上业务 KPI。

此外已清理商家界面的教学、作业、Mock、技术场景选择器和学术式提示。数据口径、缺失部分、预算影响、确认与撤销等实际决策所需信息继续保留。当前八屏及补充状态截图共 13 张，位于 [assignment-2/screenshots](assignment-2/screenshots/)；旧 screenshots 目录保留为历史资产。

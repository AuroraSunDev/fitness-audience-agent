# 作业二原型：3 条实际走查发现

以下问题均在 390 × 844 浏览器点击主链路时复现，已修复并重新走查。它们不是商家真实数据的效果验证。

1. **切屏后仍停留在旧滚动位置（高）**：从长结论页底部进入 S7／S8，初次进入时标题被滚到屏幕外，店长可能直接看见中间字段。修复为屏幕状态改变时回到顶部，同屏编辑不重置滚动；浏览器测试断言新屏 `scrollY = 0`。
2. **预算二次确认时有两个同名提交按钮（高）**：弹窗打开后，弹窗与底部固定操作栏都保留「提交审批」，既妨碍自动化定位，也可能造成重复操作。修复为弹窗期间隐藏底部操作栏，仅保留弹窗内一次提交入口；完整点击链路重新通过。
3. **修改巡检频率后仍显示已订阅（中）**：保存并开启模拟订阅，再把每日改为每周，旧开关仍亮，但计划状态已变为未保存。修复为改动频率／通知方式立即关闭旧模拟订阅、保存本机状态，并提示「重新保存后再开启」；用浏览器断言开关从 `true` 变为 `false`。

剩余边界：数据和工具调用均为固定 Mock；「接管」「审批」「订阅」只在浏览器内展示状态，不可作为真实经营系统或真实投放测试使用。

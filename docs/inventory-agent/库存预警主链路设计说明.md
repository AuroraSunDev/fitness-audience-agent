# 库存预警 Agent｜主链路设计说明（一页版）

**版本** v1.1｜**使用者** 品牌负责人、库存计划员｜**目标** 让结论可追溯、动作受控、失败可解释。

## 从发现到处置

| 页面 | 关键决策与操作 |
|---|---|
| S1 总览 | 品牌、店铺、仓库三级切换；查看健康度、P0/P1/P2 数量和当前仓库存资金占用。 |
| S2 预警 | 默认按影响金额降序，可切换级别优先；支持筛选、批量指派、带原因关闭误报。 |
| S3 详情 | 查看逐日历史库存、分仓可售、普通在途、活动与到货预测。 |
| S4 证据 | 核对指标 ID、v1.2 口径、时间窗、来源、血缘和取数时间，可复制。 |
| S5 归因 | 查看主因排序、解释权重和每项可复核证据。 |
| S6 建议 | 核对动作、数量、费用、时效、预估影响及失效条件。 |
| S7 审批 | 预览影响并二次确认；生成模拟审批单号后可跟踪、撤销。 |
| S8 异常 | 显示数据延迟、无数据、取数失败、超时和证据冲突的未知部分与人工路径。 |

**时间与口径。** 全局采用中国标准时间。标准样例的判断时点为 **2026-11-15 09:10**，库存快照为 **09:00**，取数为 **09:05**；趋势仅含 **11 月 8—15 日 09:00** 的历史点，未来到货明确标为预测。日销取 **10 月 16 日—11 月 14 日** 30 个完整日。可售 v1.2＝实物－锁定－残次＋已达可售条件的在途；普通采购在途不计入。缺货影响金额为预计毛利损失，积压、周转和慢动销金额为当前仓可售库存成本。

**主案例。** `YM-2048` 可售 `190－20－2＝168` 件；30 日销售 720 件，日销 24 件；安全库存 `24×9×1.2＝259.2` 件。采购单 120 件预计 11 天后到仓，按现有日销推算到货前缺口 `24×11－168＝96` 件。建议从 B 仓调拨 **120 件**（96 件缺口＋24 件缓冲），2 天到达、费用 ¥480；B 仓调出后为 220 件。按每件贡献毛利 ¥45 估算，可规避毛利损失 ¥4,320，扣费后净影响约 ¥3,840。

**能力边界与上下文。** 当前页面使用固定情景数据；对话按当前筛选范围、SKU、证据和审批状态回答。页面中的审批、撤销、重取数据均为本地模拟状态，不连接实际库存、采购或审批系统。每轮只保留角色与授权范围、筛选条件、SKU、时间窗、口径版本、证据和审批状态；切换范围或 SKU 后重选分析对象。

**停止与失败处理。** 缺关键数据、时点不一致、权限不足、低置信度或建议失效时暂停建议和审批。快照延迟超过 6 小时显示旧时点；无记录显示“无数据”而非 0；取数失败重试一次后转人工；超过 90 秒保留阶段结果。证据冲突时指出冲突值并要求复核。审批通过、执行回写和效果核验分属不同状态，只有核验后才能关闭风险。
